# Ontology（歧义索引）

> [!tip] 核心本质
> 在 AI 圈说「ontology」至少指两条线：**Palantir Foundry 上的运营世界模型（对象 + 动作 + 治理）**，或 **语义网意义上的形式化领域规格（OWL/RDF/SHACL）**。混用会导致选型对话完全错位——前者要买/用 Foundry 生态，后者要本体工程与推理校验栈。

**你要找的若是 Palantir 那套框架**（常与 AIP、OAG、MCP 一起出现），请读 **[[palantir-ontology]]**——这才是 2025–2026 企业 Agent 语境里「ontology 很火」时多数文章所指的产品层。

**你要找的若是语义网 / 知识工程里的本体**（Competency Questions、Protégé、OWL 公理、SHACL 校验），本库暂无专文；机制片段见 [[knowledge-fusion]]（本体对齐）、[[knowledge-extraction]]（schema 再实例化）、开放标准 [W3C OWL 2 Overview](https://www.w3.org/TR/owl2-overview/)。

*检索说明：歧义澄清依据 [Palantir Ontology overview](https://www.palantir.com/docs/foundry/ontology/overview/) 与经典 KG 综述 [arXiv:2510.20345](https://arxiv.org/html/2510.20345v1)（观测 2026-06-21）。*
